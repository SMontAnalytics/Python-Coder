# 🚗 Concesionario de Autos en Python

Esta es una aplicación web desarrollada con Django, consiste en un concesionario de vehículos en donde se puede gestionar todo lo relacionado con la compra y venta de estos, para su desarrollo se utilizo principalmente lenguaje Python.

## 🌟 Características

- **Gestión de Vehículos**: Visualización detallada de marcas, modelos y especificaciones de autos.
- **Sistema de Usuarios**: Registro, inicio de sesión y perfiles personalizados.
- **Perfiles con Avatar**: Los usuarios pueden subir y visualizar su foto de perfil en la barra de navegación.
- **Diseño Moderno**: Interfaz estilizada con una paleta de colores profesional (Azul, Plateado y Gris) utilizando **Bootstrap 5**.
- **Sección 'Acerca de'**: Información sobre el propósito del proyecto.
- **Panel Administrativo**: Acceso total para la gestión de la base de datos a través de Django Admin.

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** [Python 3.x]
* **Framework Web:** [Django]
* **Base de Datos:** SQLite (desarrollo)
* **Frontend:** HTML5, CSS3, Bootstrap 5.
* **Control de Versiones:** Git & GitHub.
